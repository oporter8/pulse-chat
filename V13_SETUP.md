# Tiger Chat v13

1. Run `supabase/v13_customization_terms.sql` in Supabase SQL Editor.
2. Run `npm run build`.
3. Test signup, `/terms`, `/privacy`, `/customize`, `/chat`, `/community`, `/support`, and `/moderation`.
4. Theme recovery: add `?safeTheme=1` to a Tiger Chat URL or press Alt+Shift+R.
5. After testing, commit and push from the pulse-chat repository directory.

Custom CSS is CSS-only: remote `url(...)`, `@import`, executable CSS, and remote image assets are blocked.
