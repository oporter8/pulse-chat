# Tiger Chat v13.1 — Customization + Mobile

No new Supabase migration is required. Existing v13 theme JSON automatically gains safe defaults for the new settings.

After applying:

```bash
cd ~/Downloads/pulse-chat
npm run build
```

Test `/customize` on desktop and a phone-sized browser, then test `/chat`, Settings, Community, Support, and Moderation on mobile.

Mobile conversation mode can hide the global bottom nav so the open chat uses the full screen. Theme recovery remains Alt+Shift+R or `?safeTheme=1`.
