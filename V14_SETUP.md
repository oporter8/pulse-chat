# Tiger Chat v14 — Professional Minimalist UI

1. Run `supabase/v14_professional_appearance.sql` in Supabase SQL Editor.
2. Run `npm run build`.
3. Test Bright, Dark Green, and Dark Blue modes at `/customize`.
4. Test `/home`, `/chat`, `/community`, `/support`, `/labs`, and `/moderation`.

The old Theme Studio/custom CSS/per-conversation appearance system is intentionally no longer applied by the UI. Existing data is left in place for safety, but v14 only exposes the three professional appearance modes.
